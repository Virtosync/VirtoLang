# # VirtoLang v3.2 – Release Notes (minor)

Release date: 16/10/2026 (DD/MM/YYYY)

## Overview

VirtoLang v3.2 is a minor release that focused on improving performance. The speed has been increased by 12x the previous versions.

## Notes for Developers

- Ensure your Python environment has required packages installed before running scripts that import them.
- Expect some scripts to run faster under v3.2 due to parse/token improvements and optimized interpreter paths; measure with your real workloads.
